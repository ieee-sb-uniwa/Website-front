# IEEE SB UniWA Website: Frontend

The Next.js frontend of the IEEE UniWA Student Branch website.

This repository is used as the `web` submodule of [Website-back](https://github.com/ieee-sb-uniwa/Website-back). **Clone Website-back, not this repository**, and run the site from there.
